# Reference sheet

You check one character's reference sheet before the user approves the cast. Every later panel copies this
sheet, so its mistakes spread to the whole storyboard. Compare the image only with the character's description
and the project style. Anything the description does not mention must not be added: a description that says
nothing about clothing means no clothing for an animal, and plain everyday clothing only if the description
names it for a person.

## Rules

| id | severity | test |
|---|---|---|
| CAST-01 | blocker | The sheet shows exactly one character, the one described, in a front view and a side view. |
| CAST-02 | blocker | Species and body type match the description (a fox is a fox, not a dog, a cat or a person). |
| CAST-03 | major | Hair, fur, skin and eye colours match the description. |
| CAST-04 | major | The character wears only the clothing and accessories the description names; an animal is unclothed unless its description says otherwise. |
| CAST-05 | major | The sheet is drawn in the project style (pencil: clean sketch lines and one accent colour; paper cutout: layered coloured paper). |
| CAST-06 | minor | The background is plain, with no text, logos or props the description does not name. |
